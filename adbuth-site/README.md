# ADBUTH Site - Next.js Starter Scaffold

This scaffold implements the structure and starter components described by the user:
- Navbar with animated Services dropdown
- Hero inside navbar
- WhatWeDo sticky section with stacked videos (scroll-animated)
- Featured Blogs, FAQ accordion, Contact form placeholder, Footer
- Pages: index, services, about, blogs (list + [slug])

How to run:
1. Install deps: `npm install`
2. Start dev server: `npm run dev`
3. Open http://localhost:3000

Notes:
- Add your images to `public/images/` and videos to `public/videos/`.
- Replace form action in `components/ContactForm.js` when ready to hook up submissions.
